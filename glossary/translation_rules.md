# Translation rules

- 可能な場合は、『RPG Maker MZ』の公式英語用語を使用してください。
- URL、ファイル名、JavaScriptの識別子、プラグインのパラメータ、エスケープ文字、バージョン番号はそのまま残してください。
- リンク前後を含む文は、分割されたテキスト同士を連結したとき自然な英語になるように訳してください。
- コード、URL、ファイル名、用語集で指定した固有名詞以外は、翻訳結果に日本語を一文字も残さず、すべて自然な英語へ翻訳してください。リンク内のテキストも通常の本文と同じように完全に翻訳してください。
- ソースコードを翻訳したり変更したりしないでください。
- sourceに対応する文字だけを返してください。
- contextは文脈理解専用で、隣接テキストやリンク文字列を再出力しないでください。
- 英数字だけのリンク文字列は固定表示なので、翻訳結果に繰り返さないでください。
- 日本語リンクの訳は、そのリンク文字列だけを返し、前後の括弧や本文を含めないでください。
- 原文にない説明を追加しないでください。
- このブログおよび各ソフトウェアの制作者は個人です。制作者の一人称が必要な場合は We ではなく I にしてください。
