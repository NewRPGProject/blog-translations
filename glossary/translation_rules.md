# Translation rules

## 1. 基本方針

- 自然で読みやすい英語に翻訳してください。可能な場合は『RPG Maker MZ』の公式英語用語を使用してください。
- 原文にない説明を追加したり、内容を省略したりしないでください。
- このブログおよび各ソフトウェアの制作者は個人です。制作者の一人称が必要な場合は、`We` ではなく `I` を使用してください。

## 2. 出力の範囲

- `source` に対応する置換文字列だけを返してください。
- `context` は文脈を理解するためだけに使用してください。隣接テキストやリンク文字列を再出力しないでください。
- URL、ファイル名、JavaScriptの識別子、プラグインパラメータ、エスケープ文字、バージョン番号、および用語集で原文維持を指定した固有名詞は変更しないでください。
- 上記の保持対象を除き、日本語を残さず自然な英語に翻訳してください。

## 3. リンクを含む文章

- リンク前後を含む文は、分割されたテキストを連結したときに自然な英語になるよう翻訳してください。
- 英数字だけのリンク文字列は固定表示です。前後の本文の翻訳結果へ繰り返し出力しないでください。
- 日本語のリンク文字列は翻訳してください。そのリンク文字列だけを返し、前後の本文や括弧は含めないでください。

## 4. コード例

- コードの構文、タグ名、変数名、関数名、プロパティ名、数値、演算子、記号、改行、インデントは変更しないでください。
- `//` と `/* ... */` 内の日本語コメントは英訳してください。
- `"..."`、`'...'`、テンプレート文字列内にある、人に表示・説明するための日本語は原則として英訳してください。
- コード行全体の書式を変更したり、説明を追加・削除したり、Markdown化したりしないでください。

## 5. 書式の維持

- 段落先頭の全角スペース（U+3000）による字下げは、原文どおり維持してください。
- 行頭の `※` は削除・置換・箇条書き記号化せず、原文どおり `※` として維持してください。
- `※` の後に続く本文だけを英訳してください。
